# claude-skills

A collection of [Claude](https://claude.ai) skills.

## Skills

| Skill | Description |
|---|---|
| [`academic-paper-reading-assistant`](academic-paper-reading-assistant/SKILL.md) | Turn a technical paper (pure maths, theory, ML or other empirical work; arXiv link/id, PDF and/or LaTeX source) into one reading-copy PDF: a front reading guide (key references, argument graph, reading route, exercises) plus the paper with route sections boxed. |

## Installation

Each skill lives in its own folder containing a `SKILL.md`. To use one with Claude Code, copy the folder into `~/.claude/skills/` (personal) or `.claude/skills/` in a project. On claude.ai, zip the folder and upload it under Settings → Capabilities → Skills.
